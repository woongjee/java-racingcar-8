# java-racingcar-precourse
## 개요
랜덤으로 전진/정지하는 초간단 자동차 경주 게임을 구현한다.

## 기능 요구 사항
- 주어진 횟수 동안 n대의 자동차는 전진 또는 정지
- 자동차 이름 부여 가능
- 자동차 이름은 쉼표를 기준으로 구분(5자 이하)
- 이동 횟수 입력
- 전진하는 조건은 0~9 사이의 무작위 값을 구한 후 4 이상일 경우
- 우승자 출력(우승자는 한 명 이상)
- 우승자가 여러 명일 경우 쉼표를 이용하여 구분
- 잘못된 값 입력 시 IllegalArgumentException을 발생시킨 후 애플리케이션 종료

---

## 클래스별 역할

---
## Controller
### RacingGameController
- 전체 게임 흐름 제어
- View와 Service 연결

### RaceController
- 자동차 초기화
- 경주 진행 제어
- 우승자 조회

---

## Service
### RaceService
- 난수 생성(0~9)
- 각 자동차에 대해 전진 처리
- 우승자 찾기
- 단독/공동 우승자 목록 반환

---

## View
### InputView
- 자동차 이름 입력 받기
- 시도 횟수 입력 받기
- 입력값 파싱

### OutputView
- 실행 결과 출력
- 각 라운드마다 자동차 위치 출력
- 단독/공동 우승자 출력
- 에러 메시지 출력

---

## Model
### Car
- 자동차 이름 저장
- 현재 위치 관리
- 전진 조건 확인 및 이동 처리

### CarFactory
- 입력 받은 이름으로 Car 객체 생성
- Car 리스트 생성

---
## 예외 처리
### InputValidator
- 빈 입력 값 검증
- 자동차 이름 길이 검증(5자 이하)
- 자동차 이름 중복 검증
- 빈 이름 검증
- 시도 횟수 양의 정수 검증
- IllegalArgumentException 발생
